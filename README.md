# fosombat-pages

Static build of **[FOSOMBAT](https://github.com/fosemberg/fosombat)** — a mobile-first 3D fighting game with raw WebGL2 rendering, serverless WebRTC multiplayer and the Temporal Echo mechanic.

- Play: https://fosemberg.github.io/fosombat-pages/
- Component workshop (Storybook): https://fosemberg.github.io/fosombat-pages/storybook/

The `docs/` folder is generated by `npm run build:pages` in the source repository. Do not edit it by hand.

GitHub Pages settings: *Deploy from a branch* → `main` → `/docs`.
